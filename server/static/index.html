适用范围与限制 / Scope & limits

项目限制说明
靶点蛋白大小 Boltz-2：单链 ≤ 4096 残基，单 GPU 约 ≤ 2000 残基总量；Chai-1：本地 ≤ 2048 token，API ≤ 1024 残基。 MD 验证受 CPU 算力限制，建议靶点 + 结合剂总量 < 500 残基，否则耗时极长。
翻译后修饰（糖基化 / 磷酸化等） 结构预测阶段可输入含修饰的输入，但 MD 验证当前不建模 PTM：糖基（NAG/BMA/MAN 等）、 磷酸基等非标准残基会在 MD 前被剥离，仅按 20 种标准氨基酸处理。如需糖基化结合剂的稳定性评估，属后续规划能力。
其他非标准残基MD 阶段仅支持标准 20 种氨基酸（及 MSE/SEP/TPO）；配体、离子、水会在 MD 前被移除。
具体上限依所连接的在线服务（NVIDIA NIM / boltz.bio / Chai）与算力而异。
